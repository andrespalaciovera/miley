# 00 Vision and Principles

## Goal
Build a **sellable, CRO-optimized Shopify theme** designed specifically for the specialty consumables niche (supplements, coffee, tea, gourmet foods).

## Core Insight & Thesis
General themes are built around physical products (image -> color/size -> Add to Cart). 
Consumable brands sell *information, confidence, replenishment, and bundles*. 
The PDP journey must flow as: **Understand -> Evaluate -> Trust -> Choose -> Commit**.

## Governing Principles
1. **Eliminate the Essential App Tax:** Provide native versions of what merchants always pay apps for (pack economics, slide carts, facts panels, product profiles).
2. **Mobile First, Not Mobile Adapted:** Use dedicated mobile controls. Do not rely on desktop-only settings.
3. **Vanilla Web Components:** No jQuery or heavy frameworks. Async load scripts; initialize only when a section enters the viewport.
4. **Zero-Code Styling, Zero-Fear Updating:** All design tokens must use CSS custom properties. No raw hex codes in CSS. Keep custom code strictly isolated from core files.
5. **Fail-Safe PDP Mechanics:** The picker, URL params, gallery, unit price, and sticky ATC must form one reactive loop.
6. **Tasteful Conversion:** Focus on elegant CRO. No fake timers, spinning wheels, or dropship clutter.
7. **Native International Readiness:** Support multi-market, tax inclusion, and unit prices.
